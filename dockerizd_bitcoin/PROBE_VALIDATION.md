# اعتبارسنجی گام سوم بیت‌کوین — ۲۰۲۶-۱۰-۲۳

دامنه: **ING-01**، ابزار بررسی آمادگی Bitcoin Core در `bitcoin_aml probe` و
مسیر اجرای یک‌بارمصرف `bash scripts/vm.sh bitcoin probe` روی VM بیت‌کوین.
ClickHouse هر شبکه روی VM خودش باقی می‌ماند. schema مشترک نسخهٔ ۱، checksum،
وابستگی‌ها و writer/reader اتریوم در این گام تغییر نکرده‌اند.

## نتیجهٔ اجرا

| بررسی | نتیجه |
|---|---|
| `cargo test --locked --offline --all-targets -- --include-ignored` | ۲۷ آزمون بیت‌کوین پاس شد: ۷ واحد، ۲ نگاشت، ۱۶ probe و ۲ pipeline واقعی ClickHouse |
| `cargo clippy --locked --offline --all-targets -- -D warnings` | روی سورس نهایی پاس شد |
| مجموعهٔ Linux CLI | تمام گروه‌ها، شامل probe، اجرای یک‌بارمصرف بدون وابستگی، حفظ نام پروژه و رد گزینه‌های نامعتبر پاس شدند؛ Docker/HTTP/Cargo در این مجموعه test double هستند |
| ۴۴ آزمون Python | ابزار VM، اجرای محلی و inventory پاس شدند |
| پیکربندی Compose با profile ابزار | سرویس probe بدون `depends_on`، بدون پورت منتشرشده و بدون متغیر ClickHouse/کلید API؛ تنظیمات RPC و بازه با ingestion یکسان‌اند |
| تطبیق سورس و قرارداد | سورس فعال با سورس آزمون‌شده برابر بود؛ فایل schema مشترک و runtime اتریوم تغییر نکردند |

آزمون‌های Rust در Docker با Rust 1.92 و وابستگی‌های قفل‌شده اجرا شدند.
ClickHouse نسخهٔ 23.8 خالی و موقت و RPC کنترل‌شده با رمزهای ساختگی استفاده شد؛
فایل خصوصی محیطی به کانتینر آزمون mount نشد و دیتابیس عملیاتی تغییر نکرد.

## شواهد مربوط به probe

- نام mainnet و genesis؛ رد شبکه یا genesis اشتباه پیش از دریافت تراکنش‌ها.
- ارتفاع بلاک/header، sync، زمان قدیمی tip و نبود بازهٔ تأییدشده.
- رد تاریخچهٔ prune‌شدهٔ لازم و گزارش محدودیت برای بازهٔ باقی‌مانده.
- resolve از undo/prevout، خروجی تراکنش قبلی همان بلاک و lookup واقعی تاریخی.
- تفکیک شروع تازه از وسط زنجیره با prevout ناموجود از replay ترتیبی از genesis
  که ممکن است به خروجی‌های ذخیره‌شدهٔ محلی متکی باشد؛ دیتابیس بررسی نمی‌شود.
- ادعای txindex بدون lookup موفق کافی نیست؛ metadata ناموجود یا index عقب‌مانده
  با قطعیت ساختگی جایگزین نمی‌شود. نبود index با undo قابل استفاده مانع نیست.
- verbosity ۳ ناموفق و verbosity ۲ موفق فقط پیشنهاد تنظیم می‌دهند؛ تنظیمات
  ingestion خودکار تغییر نمی‌کنند و پیکربندی فعلی آماده اعلام نمی‌شود.
- دادهٔ ناقص/متناقض، timeout درخواست و تغییر زنجیره هنگام بررسی گزارش می‌شوند.
- بلاک فقط coinbase، قابلیت resolve ورودی خارجی را تأیید نمی‌کند. نمونه‌گیری
  بلاک بزرگ به هشت ورودی در هر بلاک و ۱۶ lookup در کل محدود است.
- اجرای واقعی باینری بدون هیچ تنظیم ClickHouse و کلید API: JSON و کد خروج
  ۰/۲/۱ برای ready/degraded/unready، راهنمای مستقل و تنظیمات ناقص بررسی شدند.
- فقط متدهای خواندنی RPC استفاده شدند؛ endpoint، رمز و متن خام خطای provider
  وارد خروجی تشخیصی نشدند.

سقف کلی ۱۲۰ ثانیه در ابزار اعمال می‌شود. آزمون timeout، مهلت یک‌ثانیه‌ای client
را روی RPC متوقف‌شده بررسی کرده است؛ برای آزمون خودکار ۱۲۰ ثانیه صبر نشده است.

## محدودیت و کار باقی‌مانده

این مرحله به Bitcoin Core واقعی یا نود مستقر متصل نشد. بررسی روی دو بلاک نمونه
تأیید کل تاریخچه، ظرفیت RPC، صحت تمام prevoutها، سلامت دیتابیس، restart از
checkpoint واقعی یا استقرار پنج VM نیست. `ready` فقط نتیجهٔ همین بررسی محدود
است؛ فیلدهای `local_database_checked` و `full_history_verified` صریحاً false هستند.

ابزار probe داده‌ای در ClickHouse ذخیره نمی‌کند و checkpoint را تغییر نمی‌دهد.
retry/backoff، endpoint جایگزین، مالکیت writer و دریافت batch دامنهٔ **ING-02**
هستند؛ نتیجهٔ مرحلهٔ بعد در [گزارش دریافت](INGESTION_VALIDATION.md) ثبت می‌شود.
failure/repair در **ING-03** و قابلیت‌های تحلیلی AML در مراحل جدا باقی مانده‌اند.
بیت‌کوین هنوز از نظر تمام امکانات با شبکه‌های قبلی هم‌سطح نشده است.

دستورها و معنی وضعیت‌ها در [راهنمای بیت‌کوین](README.md) و فهرست کامل در
[TODO](../TODO_BITCOIN.md) آمده‌اند. قرارداد RPC در همان راهنما به مستندات رسمی
Bitcoin Core پیوند داده شده است.
